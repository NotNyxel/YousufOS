Adhan audio
===========

Bundled recordings (see CREDITS.md):
  makkah.mp3  madinah.mp3  mishary.mp3  dubai.mp3  fajr.mp3  takbir.mp3

To use your own, put an MP3 with the same name in ~/Music/Adhan/ - it takes
priority over the bundled one. sheikhzayed.mp3 has no bundled recording: add
~/Music/Adhan/sheikhzayed.mp3 for the "Sheikh Zayed Mosque" voice (until then
the Dubai adhan plays).

"Custom" plays the file in config.json -> adhan.customPath.
